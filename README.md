# Telegram Manager

Модульный Telegram-бот для владельцев каналов: рекламные заявки, их согласование, расписание и публикация.

## Быстрый старт

1. Создайте бота через @BotFather.
2. Скопируйте `.env.example` в `.env` и укажите `BOT_TOKEN`.
3. Установите Python 3.12+ и зависимости: `pip install -r requirements.txt`.
4. Запустите `python -m app`.

Первый этап: базовый бот с меню и заготовкой модуля рекламных заявок. Приём платежей пока не реализован.

### Безопасность

Никогда не публикуйте токен бота или пароли. `.env` исключён из Git.

### Автопроверки

GitHub Actions запускает проверку синтаксиса Python на каждом push и pull request.
